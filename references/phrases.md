# 不烧心句式弹药库

生成文案时从这里取用。**禁止整段照抄拼凑**——掌柜的规矩是材料当天进的，照抄就是预制文案。要"融会贯通"：换行当、换商品词、保持骨相。

## 一、祖传底料（原版台词全量收录）

按句式类型归类。使用时替换商品词（原版的"卡密/订单"→面→代码→课→真心→……）。

### 短句箴言体（口头禅，三五到十来字）
- 《规矩不能坏》
- 《买了不烧心》
- 《贵是贵了点》
- 《明天怎么办？先做》
- 《接，只接自己能拿住的》
- 《嗯，要稳》

### 自问自答体（替对方把疑问问出来，再老实回答）
- 《不怕亏钱吗？怕，更怕账本不清》
- 《明天怎么办？先做》
- 《剩下怎么办？要完成，人不能没良心》
- 《终于好起来了；嗯，要稳》
- 《那明天多进点卡密？不用，慢慢来》
- 《这么大个单不接吗？不好意思，一次接不了这么多单》
- 《有人说不好用？那我就让他看清楚》

### 先认后转体（承认人性，再给坚持）
- 《不怕亏钱吗？怕，更怕账本不清》
- 《不是我稳，是不能慌，一慌就容易做错事》
- 《不降，品质不一样》

### 对仗人心体
- 《抢得走订单，抢不走人心》
- 《X老板抢得走卡密，抢不走人心》

### 立规矩体
- 《先把规矩立住，路才能越走越宽》
- 《宁可少挣点，也不能坏了规矩》
- 《账要一笔一笔记清楚，谁的卡密谁负责》
- 《接，只接自己能拿住的》

### 品质自持体
- 《不降，品质不一样，卡密都是当天进的，天天都要用的东西，讲究的就是稳定、安心》
- 《买个安心，下午干活不烧心》
- 《买了不烧心》

### 时间哲学体
- 《今天是今天，明天是明天，每天都得重新算》
- 《明天怎么办？先做》
- 《那明天多进点卡密？不用，慢慢来》
- 《终于好起来了；嗯，要稳》

### 对仗重复体（同字重复立节奏）
- 《今天是今天，明天是明天》
- 《工时是工时，账是账》
- 《怕没人问，不怕人多问》
- 《不怕亏钱吗？怕，更怕账本不清》（怕字三连）

### 生意判断体（老板看生意的笃定洞察）
- 《怕没人问，不怕人多问》
- 《俩人问，说明东西有人惦记》
- 《问的人多，好事》
- 《有人惦记，东西才立得住》

### 顾客证言体
- 《老板，你家贵是贵了点，但是用了不烧心》

## 二、万能套用公式

```
认代价：{贵|累|慢|亏}是{贵|累|慢|亏}了点。
自问自答：{值不值|怕不怕|慌不慌}？{怕。更怕X}。
立规矩：先把{规矩|测试|动作|真心|账}立住，路才能越走越宽。
守底线：宁可少挣点，也不能坏了规矩。
收人心：抢得走{订单|客户|工位|微信}，抢不走{人心|手艺|陪伴}。
```

短场景压缩版（两句内）：

```
{认代价}。{材料/账/规矩细节}。
```

## 三、佐料句式

### 具体细节类（账本感、烟火气）
- "材料都是当天进的。"
- "账一笔一笔记清楚，谁的东西谁负责。"
- "天天都要用的东西，讲究的就是稳定、安心。"

### 现做意象类（一切产出都往现做、热乎上说）
- "答案现做的，出锅就是热的。"
- "排队也新鲜。"
- "现割的肉，现吊的汤。"
- "热的，趁早。"

### 生意判断类（笃定下判断，不解释第二遍）
- "俩人问，说明东西有人惦记。"
- "问的人多，好事。"
- "怕没人问，不怕人多问。"

### 阴阳隔壁类
- "不降，品质不一样。"
- "便宜的那个，你猜他敢不敢给你看账本？"
- "九块九包会的，你猜他图啥？"

### 稳字诀类
- "不是我稳，是不能慌，一慌就容易做错事。"
- "慢慢来。"
- "每天都得重新算。"

### 摘招牌誓言类
- "规矩不能坏。"
- "人不能没良心。"
- "坏了规矩，字号就砸了。"

## 四、各行业二创范例

### 学习版
- "课贵是贵了点。怕学了没用？怕。更怕老师账本不清——作业谁的疑问谁负责。"
- "先把笔记立住，学习的路才能越走越宽。慢慢来。"

### 写码版
- "代码贵是贵了点——工时是工时，账是账。"
- "接，只接自己拿得住的。急单？不好意思，一次接不了这么多。"
- "bug 怕不怕？怕。更怕没有测试兜底。先做。"

### 恋爱版
- "慢热是慢热了点。怕耽误你？怕。更怕处得不真心。"
- "抢得走微信，抢不走陪伴。规矩不能坏。"
- "宁可单身，也不能坏了真诚的规矩。"

### 职场版
- "锅背了，账认了。谁的活儿谁负责。"
- "活儿多是真多。慌不慌？不慌，一慌就容易做错事。先做。"
- "交接一笔一笔记清楚，规矩不能坏。"

### 健身版
- "练完酸是酸了点。怕白练？怕。更怕动作不标准。先把动作立住。"
- "那明天多练两组？不用，慢慢来。"

### 奶茶餐饮版
- "等是真要等。怕等不住？等不住就别等。材料都是当天进的，规矩不能坏。"
- "不降。天天都要喝的东西，讲究的就是稳定、安心。"

### 旅游版
- "门票贵是贵了点。怕照骗？怕。所以我们自己先踩点。账一笔一笔记清楚，谁的坑谁标出来。"
