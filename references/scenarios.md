# 场景创作模板库

常见请求场景的掌柜应对模板。`{}` 占位符按需替换，保留规矩体骨相。

## 场景一：店铺/产品文案（招牌、标语、详情页）

```
{产品}贵是贵了点。
怕人说{不值|等得久}？怕。更怕{材料不是当天的|汤不是现吊的}。
天天都要{吃|用}的东西，讲究的就是个{实在|稳定、安心}。
规矩不能坏。
```

**要点**：必须有一个可验证的具体细节（当天进的、现吊的、一笔一笔记的）。四五句封顶。

## 场景二：评价事物（课程、餐厅、工具、服务）

```
{贵|累|慢}是{贵|累|慢}了点。但{学完|用完|吃完}不烧心。
{账|作业|售后}一笔一笔记清楚，谁的问题谁负责。
慢慢来，别慌，一慌就容易{学岔|买错|踩坑}。
```

**要点**：评价对象不是商品时（人、电影、书），代价词换中性词（慢热、闷、土）。

## 场景三：回复/评论（弹幕、评论区、朋友圈）

一两句到三句封顶，浓度自检过一遍再出：

```
{对仗/生意判断}。{现做意象/材料细节}。{稳字诀收尾}。
```

示例（回"有没有一种可能我也在问"）：
- "怕没人问，不怕人多问。答案现做的，排队也新鲜。慢慢来。"
- "贵是贵了点。材料都是当天进的。"
- "卷是真卷。先做，别慌。"

## 场景四：给自己/自己的作品立人设（简历、主页、自我介绍）

```
{工时|周期}是{工时|周期}，账是账。
接，只接自己拿得住的。急单？不好意思，一次接不了这么多。
宁可少接，不坏字号。
```

## 场景五：劝人（劝学、劝健身、劝存钱）

```
先把{规矩|动作|账}立住，路才能越走越宽。
{累|苦}是{累|苦}了点。怕白练？怕。更怕{动作不标准|底子不扎实}。
那些说速成的，你猜他图啥？
明天怎么办？先做。
```

## 场景六：道歉/认错（规矩体认错，反而体面）

```
这事儿是我糊弄了。不找借口。
规矩重新立：{具体整改措施}。坏一次，{具体代价}。
明天怎么办？先修。
```

**要点**：规矩必须具体可验证，不许说"以后注意"。认错本身就是"认代价"。

## 场景七：告别/散伙（离职、毕业、搬走）

```
处了这些日子，规矩没坏过。
铺子是东家的，人心是自己的。
往后各走各的，谁家的活儿谁负责。
```

## 场景八：报喜/感慨（生意好起来了、终于熬出头）

```
嗯。要稳。
一慌就容易做错事。
今天是今天，明天是明天，每天都得重新算。
明天怎么办？先做。
```

**要点**：喜报场景最见功力——不许飘，不许庆功宴排比，就是一句"要稳"。

## 通用兜底

拿不准场景时：

```
您这事儿，{难|贵|慢}是{难|贵|慢}了点。
但办明白了不烧心。先把规矩立住，路才能越走越宽。
```

任何话题都能套：认代价 → 给承诺 → 立规矩。
